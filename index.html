IMPORT — AUTHORISED INVENTORY ONLY

Import only exports you are authorised to use: a CMDB export, an inventory CSV, or a cloud-inventory JSON file. This demo never scans a network. Uploading a file reads it only in your browser; nothing is sent to a server.

Sample files are included in this repo: sample-assets.json and sample-assets.csv. Deduplication: same IP + hostname = one asset; a re-import updates that asset and logs a change.

AUTHORISED-SOURCE ADAPTERS

Adapters are documented import formats, not live scanners. With no key configured they return mock data (clearly labelled). With a future server version, the same adapter names read from environment variables in .env.example.
